# Felis Continuum

Felis Continuum is an experimental 3D domestic-cat life simulator. It is built around a continuously evaluated animal controller: the cat perceives the habitat, updates spatial and event memory, weighs competing motivations, forms a persistent intention, plans a route, and only then drives navigation, locomotion, whole-body procedural pose, paw placement, gaze, and interaction.

No photographs, video frames, cat meshes, textures, or animation clips are shipped. The cat and habitat are generated by code from observations across many real animals and published anatomy/motion studies. See [RESEARCH.md](RESEARCH.md).

## Controls

- Point at real objects or the cat to reveal a small contextual prompt.
- Click and drag across the cat to pet the body region beneath the pointer.
- Click bowls, door hardware, litter tray, treat jar, toys, boxes, and other affordances directly.
- Pick up a toy, aim into the world, and click to throw it; `R` drops a held object.
- `Shift` + `E` while targeting the cat requests a careful pickup.
- `Q` whistles/calls the cat.
- Drag empty space to orbit; wheel zooms.
- `WASD`, `Space`, and `Shift` move the free camera.
- `D` toggles diagnostics. `H` hides/restores the normal interface.

The HUD fades while the player watches. Cat status is collapsed by default and expands only when selected.

## Architecture

```text
habitat + physics + player events
               ↓
           perception
               ↓
     memory + needs + personality
               ↓
       competing utility scores
               ↓
     persistent intention + plan
               ↓
       A* route + local steering
               ↓
 gait oscillator + planted-paw IK
               ↓
 anatomy + fur + gaze + micro-motion
```

The cognition loop runs independently from rendering. Physics and locomotion use fixed time steps; animation consumes motion state and never chooses goals.

## Development

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd test
npm.cmd run package:win
```

The packaged Windows application is emitted under `release/Felis Continuum-win32-x64/Felis Continuum.exe`. It is self-contained and uses no CDN or runtime network request.

### Anatomy validation captures

With the development server running, a second terminal can render the smooth
base cat from five deterministic diagnostic angles:

```powershell
npm.cmd run screenshot:anatomy
```

The command writes side, front, top-three-quarter, standing, and walking views
plus a machine-readable health manifest to `screenshots/anatomy-validation/`.
It exits nonzero for renderer faults, blank frames, missing fur suppression, or
any compatibility shim required by an incomplete rig integration.
